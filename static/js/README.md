# Student Management System

A comprehensive Student Management System built with Flask and SQLite.

## Features

- **Multi-role Authentication**: Admin, Teacher, and Student roles
- **Student Management**: Add, edit, delete, and view students
- **Course Management**: Create and manage courses
- **Instructor Management**: Manage faculty/instructors
- **Department Management**: Organize by departments
- **Enrollment System**: Enroll students in courses
- **Attendance Tracking**: Mark and view attendance
- **Grade Management**: Record and calculate grades
- **Notification System**: User notifications
- **Audit Log**: Track all system activities
- **Search & Pagination**: Easy data navigation
- **Responsive Design**: Works on all devices
